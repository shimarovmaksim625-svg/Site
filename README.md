# LISTDOMEN — учебный прототип сайта, версия 2

Прототип сайта PR-агентства (юридически — ИП Истомина), собранный по айдентике
из `identity/`. Это демонстрационный сайт: контакты, реквизиты, цифры и кейсы —
заглушки, форма никуда не отправляет данные.

Версия 2 отличается структурой: сайт разбит на шесть полноэкранных разделов,
между которыми переключаются по верхней панели. Длинного скролла по странице нет —
на экране всегда один раздел целиком. На планшетах и телефонах панель
сворачивается в кнопку-бургер с выпадающим меню разделов.

## Что внутри

```
index.html            — шесть разделов и форма заявки
privacy.html          — демонстрационная политика конфиденциальности
assets/styles.css     — стили, фирменные токены и адаптив
assets/main.js        — переключение разделов, hash-навигация, форма
assets/glow.js        — свечение за курсором на всех страницах
assets/logo-mark.svg  — знак LD для вкладки браузера
identity/             — исходная айдентика (не изменялась)
```

## Айдентика

Все акценты — только коралловый `#FF5A43` из айдентики; остальные тона
нейтральные (carbon, slate, серые):

| Роль | Значение |
| --- | --- |
| Главный акцент | Coral `#FF5A43` |
| Основной фон | Carbon `#14171A` |
| Вторичный тон | Slate `#3A424E` |
| Текст / фон | White `#FFFFFF` |
| Заголовки | Unbounded (700–900) |
| Основной текст | Manrope (400–700) |
| Служебные подписи | Space Mono (только латиница и цифры) |

Кнопки основного действия — коралловые с тёмным текстом `#14171A`: так контраст
проходит WCAG AA (белый текст на `#FF5A43` даёт только 3.09:1). В айдентике
тёмный текст на коралле уже используется в инвертированной версии знака.

## Структура сайта

Разделы идут в порядке верхней панели, у каждого свой адрес:

| № | Раздел | Адрес | Содержание |
| --- | --- | --- | --- |
| 01 | Главный экран | `#home` | Заголовок, кнопка «Оставить заявку», статистика, демо-панель медиамониторинга |
| 02 | Услуги | `#services` | Размещение, видео, аналитика и мониторинг |
| 03 | Этапы работы | `#process` | Бриф → стратегия → производство → отчёт |
| 04 | Портфолио | `#portfolio` | Четыре демонстрационные карточки с пометкой «демо» |
| 05 | Преимущества | `#advantages` | Один подрядчик, смета, скорость, отчётность |
| 06 | Форма заявки и контакты | `#request` | Форма заявки, почта, телефон, Telegram, география |

Внизу каждого раздела — один и тот же компактный подвал в духе первой версии
сайта: знак и слоган, контакты, реквизиты, документы и юридическая строка.
Он прокручивается вместе с содержимым раздела. Такой же подвал стоит на
странице политики конфиденциальности. Фон у всех разделов один — мягкое
коралловое свечение по краям на глубоком carbone из раздела «Преимущества».
Вторичные разделы получили коралловые акценты в плашках, карточках, этапах и
кейсах — без дополнительных цветов, только коралл и нейтральные тона.

## Что работает

- Переключение разделов по верхней панели без перезагрузки; адрес меняется
  (`#services`, `#portfolio` и т. д.), работают кнопки «назад / вперёд».
- Если открыть сайт с якорем, сразу показывается нужный раздел.
- Все кнопки «Оставить заявку» (`data-open-request`) переводят в раздел с формой
  и ставят курсор в поле «Имя».
- На экранах до 900 px верхняя панель заменяется бургером. Меню открывается
  поверх контента, пункты пронумерованы `01–06`, активный подсвечен, внутри —
  CTA и ссылка на политику. Закрывается по пункту, CTA, клику по затемнению,
  `Escape` и при возврате на десктопную ширину; фокус возвращается на бургер.
- Клавиатура: `←` и `→` в верхней панели переключают фокус между разделами,
  `Home` / `End` — к первому и последнему, `Enter` открывает раздел.
- Валидация полей и обязательная галочка согласия на обработку данных.
- После отправки — экран «Заявка отправлена»; кнопка «Отправить ещё одну»
  возвращает пустую форму.
- Мягкое коралловое свечение следует за курсором на всех страницах, включая
  политику конфиденциальности; на тач-устройствах отключено.
- Анимация появления элементов при смене раздела и поддержка
  `prefers-reduced-motion`.
- Без JS разделы показываются друг за другом как обычная длинная страница.
- Адаптив: 320 / 390 / 600 / 768 / 900 / 1024 / 1280 / 1440 / 1920 px.
  На телефонах — бургер-меню, одноколоночные сетки, тап-зоны от 44 px,
  поля формы 16 px (без зума iOS) и учёт `safe-area-inset`. Контент раздела
  занимает экран, подвал открывается прокруткой раздела.
- Lighthouse: Accessibility 100, Best Practices 100, SEO 100 (на локальной
  сборке; `noindex` в прототипе оставлен намеренно).

## Как открыть

Достаточно открыть `index.html` в браузере. Для проверки шрифтов и путей к
локальным файлам удобнее поднять статический сервер:

```
npx serve .
```

## Как добавить раздел

1. Добавить `<section class="screen" id="new-id" aria-labelledby="new-title">`
   внутрь `<main class="deck">` с заголовком `id="new-title" tabindex="-1"`.
2. Добавить ссылку в `<nav class="nav">` с `href="#new-id"` и `data-goto="new-id"`.
3. Пункт меню и бургер-список подхватят раздел автоматически; нумерация
   в мобильном меню строится на CSS-счётчике.

## Что заменить перед публикацией

- ИНН, ОГРНИП, телефон, почту, Telegram и адрес — сейчас заглушки.
- Цифры статистики и кейсов — демонстрационные.
- Форму подключить к бэкенду или сервису приёма заявок.
- Текст политики конфиденциальности — на проверенный юристом документ.
- Проверить домен и товарный знак LISTDOMEN (whois, ФИПС).
- Снять `noindex, nofollow` после согласования публикации.
