# LISTDOMEN — прототип сайта

Прототип сайта нового PR-агентства (юридически — ИП Истомина), собранный по
айдентике из `identity/`. Форма заявки и личный кабинет подключаются к Supabase.

## Что внутри

```
index.html            — главный экран, услуги, контакты, форма заявки
privacy.html          — демонстрационная политика конфиденциальности
assets/styles.css     — стили и фирменные токены
assets/main.js        — меню, модальные окна и анимации появления
assets/account.js     — регистрация, вход, отправка и список заявок
assets/supabase-config.js — URL проекта и публичный ключ Supabase
bd/schema.sql         — таблицы, триггер профиля и политики доступа (RLS)
assets/logo-mark.svg  — знак LD для вкладки браузера
identity/             — исходная айдентика (не изменялась)
```

## Айдентика

Токены взяты из `identity/identity_minimal.svg`:

| Роль | Значение |
| --- | --- |
| Главный акцент | Coral `#FF5A43` |
| Основной фон | Carbon `#14171A` |
| Вторичный тон | Slate `#3A424E` |
| Текст / фон | White `#FFFFFF` |
| Заголовки | Unbounded (700–900) |
| Основной текст | Manrope (400–700) |
| Служебные подписи | Space Mono (только латиница и цифры) |

Кнопки основного действия — коралловые с тёмным текстом `#14171A`: так контраст
проходит WCAG AA (белый текст на `#FF5A43` даёт только 3.09:1). В айдентике
тёмный текст на коралле уже используется в инвертированной версии знака.

## Настройка Supabase

1. Создайте проект Supabase.
2. В SQL Editor выполните `bd/schema.sql`.
3. В `assets/supabase-config.js` укажите Project URL и anon/publishable key
   из настроек проекта. Это публичные клиентские значения; `service_role` и
   secret key на сайт добавлять нельзя.
4. В настройках Auth добавьте адрес сайта в Site URL и Redirect URLs.
   Для локальной проверки подойдёт `http://127.0.0.1:8000/**`.
5. Запустите сайт из корня папки:

```
python -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/index.html`. Для модулей JavaScript и
авторизации не открывайте HTML через `file://`. Клиент Supabase загружается
из esm.sh, поэтому для работы авторизации требуется интернет.

## Что работает

- Липкая шапка, меню-бургер на телефоне, плавный скролл к услугам и контактам.
- Кнопка «Оставить заявку» (в шапке, на главном экране, в услугах и подвале)
  требует входа или регистрации, затем открывает форму.
- Регистрация и вход по email и паролю через Supabase Auth.
- Создание заявки и список собственных заявок пользователя.
- RLS ограничивает чтение и создание заявок текущим пользователем.
- Валидация полей и обязательное согласие на обработку данных.
- Адаптив от 320 px, поддержка `prefers-reduced-motion`.

Администратор может просматривать заявки в Supabase Dashboard. В клиентский
код не добавляйте `service_role` или другие секретные ключи.

## Что заменить перед публикацией

- ИНН, ОГРНИП, телефон, почту и адрес — сейчас заглушки.
- Цифры в блоке статистики (120+, 24/7, 14 дней) — демонстрационные.
- Текст политики конфиденциальности — на проверенный юристом документ с
  указанием фактического места хранения данных и условий Supabase.
- Настроить email-подтверждение, адреса возврата, резервное копирование и
  мониторинг проекта, а также защиту регистрации от злоупотреблений.
- Проверить домен и товарный знак LISTDOMEN (whois, ФИПС) — по плану практики.

Следующие шаги по плану: страницы услуг, этапы работы, портфолио,
преимущества и отдельный блок контактов.
