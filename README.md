# LISTDOMEN — учебный прототип сайта

Прототип сайта нового PR-агентства (юридически — ИП Истомина), собранный по
айдентике из `identity/`. Текущий этап — главный экран с кнопкой «Оставить заявку».

## Что внутри

```
index.html            — главный экран, услуги, контакты, форма заявки
privacy.html          — демонстрационная политика конфиденциальности
assets/styles.css     — стили и фирменные токены
assets/main.js        — меню, модальное окно, анимации появления
assets/logo-mark.svg  — знак LD для вкладки браузера
identity/             — исходная айдентика (не изменялась)
```

## Айдентика

Токены взяты из `identity/identity_minimal.svg`:

| Роль | Значение |
| --- | --- |
| Главный акцент | Coral `#FF5A43` |
| Основной фон | Carbon `#14171A` |
| Вторичный тон | Slate `#3A424E` |
| Текст / фон | White `#FFFFFF` |
| Заголовки | Unbounded (700–900) |
| Основной текст | Manrope (400–700) |
| Служебные подписи | Space Mono (только латиница и цифры) |

Кнопки основного действия — коралловые с тёмным текстом `#14171A`: так контраст
проходит WCAG AA (белый текст на `#FF5A43` даёт только 3.09:1). В айдентике
тёмный текст на коралле уже используется в инвертированной версии знака.

## Как открыть

Достаточно открыть `index.html` в браузере. Для проверки шрифтов и путей к
локальным файлам удобнее поднять статический сервер:

```
npx serve .
```

## Что работает

- Липкая шапка, меню-бургер на телефоне, плавный скролл к услугам и контактам.
- Кнопка «Оставить заявку» (в шапке, на главном экране, в услугах и подвале)
  открывает модальную форму.
- Валидация полей и обязательная галочка согласия на обработку данных.
- Экран «Заявка отправлена» (демо, данные никуда не уходят).
- Адаптив от 320 px, поддержка `prefers-reduced-motion`.
- Lighthouse: Accessibility 100, Best Practices 100, SEO 100.

## Что заменить перед публикацией

- ИНН, ОГРНИП, телефон, почту и адрес — сейчас заглушки.
- Цифры в блоке статистики (120+, 24/7, 14 дней) — демонстрационные.
- Текст политики конфиденциальности — на проверенный юристом документ.
- Проверить домен и товарный знак LISTDOMEN (whois, ФИПС) — по плану практики.

Следующие шаги по плану: страницы услуг, этапы работы, портфолио,
преимущества и отдельный блок контактов.
